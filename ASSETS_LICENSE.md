# Asset licenses

All 24 controller images (`web simulator/public/assets/*.png` and `mobile app/app/src/main/res/drawable-xxhdpi/*.png`)
are generated by `python tools/fetch_assets.py`, which downloads the packs below, extracts only the
files listed, and normalizes them (crop to content, scale, centre on a 256x256 transparent canvas).
No PlayStation / Sony artwork is used. The PS button uses a generic house glyph, not the PlayStation logo.
